## Panoramica

Modulo **Media** per la gestione completa dei contenuti multimediali: upload,
conversione video (FFmpeg), archiviazione, gestione delle risorse di
filament, integrazione S3, file management architecture e widget multimediali.
È uno dei moduli tecnici più estesi del sistema Quaeris.
