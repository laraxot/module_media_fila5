# archive/docs-legacy — Media

Documentazione storica del modulo Media rimossa da `docs/` per riportare il
conteggio dei file `.md` sotto il limite di 100 (issue #63).

## Contenuto

- `root/` — documenti sparsi dalla radice di `docs/` (analisi, report,
  appunti di sessione, duplicati e versioni supersedute)
- `stories/` — story BMAD chiuse o di sessione
- `wiki/` — wiki LLM generata (concetti, topic, integrazioni, ridondanze)
- `bmad/` — output BMAD (epics, audits, brainstorming, stories)
- `roadmap/` — roadmap e pianificazioni datate
- `_integration/`, `llm-wiki/`, `raw/`, `digests/`, `performance/`,
  `html2pdf/`, `support/`, `manuals/`, `filament/`, `ecc/`, `development/`,
  `actions/`, `relation_managers/`, `prompts/`, `outputs/`, `investigation/`,
  `resources/`, `concepts/`, `epics/`, `architecture/`, `superseded/` —
  cartelle tematiche non piu' correnti

I file `*.old*`, `*.bak*`, `*.tmp*` e i suffissi numerici (`*-N.md`) sono
stati eliminati definitivamente invece di archiviati.

Tutto il contenuto e' consultabile nel git history del repository
`laraxot/module_media_fila5`.
